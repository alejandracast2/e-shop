# Frontend Admin

Panel admin en Nuxt. Consume endpoints `admin` del backend con JWT.

## Setup
```bash
npm install
```

## Variables
- `NUXT_PUBLIC_API_URL` (default `http://localhost:4000`)
- `NUXT_PUBLIC_STORE_SLUG` (default `default`)

## Development
```bash
npm run dev
```

## Rutas
- `/` dashboard
- `/login` acceso
- `/products` catalogo admin
- `/orders` pedidos
- `/customers` clientes
